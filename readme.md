
# HojaDeVidaMovil

Aplicación móvil de hoja de vida desarrollada con React Native,
Expo y TypeScript como actividad de formación del programa ADSO del SENA.

## Funcionalidades

- Visualización de datos personales.
- Información de formación académica.
- Identificación visual de estudios en curso.
- Presentación de experiencia y proyectos.
- Sección de intereses y hobbies.
- Botones interactivos con Alert.alert().
- Navegación inferior mediante Expo Router.

## Tecnologías utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- Expo Vector Icons
- Git y GitHub

## Instalación

Clonar el repositorio:

```bash
git clone URL_DE_TU_REPOSITORIO
```

Entrar al proyecto:

```bash
cd HojaDeVidaMovil
```

Instalar dependencias:

```bash
npm install
```

Ejecutar:

```bash
npx expo start
```
